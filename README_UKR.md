# WP Top Info Bar

Плагін для WordPress, який додає керований інформаційний блок у верхній частині сайту. Блок можна налаштовувати з адмінки: текст, кольори, відступи, анімації, зображення та окремі значення для різних брейкпоінтів.

![screen](./screens/FireShot%20Capture%20067%20-%20MySite.local%20-%20[mysite.local].png)

## Призначення

Плагін створений для показу інформаційного банера у верхній частині сайту без редагування теми або шаблонів вручну.

Може використовуватись для:

- акцій та знижок
- службових повідомлень
- маркетингових банерів
- коротких інформаційних повідомлень
- додавання іконок або декоративних зображень біля тексту

![screen](./screens/FireShot%20Capture%20066%20-%20Top%20Info%20Bar%20‹%20MySite.local%20—%20WordPress%20-%20[mysite.local].png)

## Основні можливості

### 1. Керування показом блоку

- окремий пункт меню в адмінці WordPress: `Top Info Bar`
- можливість увімкнути або вимкнути показ блоку на сайті

### 2. Налаштування тексту

- текст повідомлення
- колір тексту
- розмір тексту
- зовнішній `margin`
- внутрішній `padding`
- власні CSS-класи
- власний HTML `id`

### 3. Анімації для тексту

Для тексту доступні такі варіанти:

- без анімації
- `Fade in`
- `Slide up`
- `Fade from left`
- `Fade from right`
- `Slide from page left`
- `Slide from page right`
- `Blink`
- `Scale up`

Також можна вказати затримку запуску анімації.

### 4. Додавання зображень

Плагін дозволяє додавати необмежену кількість зображень через Media Library.

Для кожного зображення доступні параметри:

- розмір
- `margin`
- власний CSS-клас
- позиція:
  - ліворуч від тексту
  - праворуч від тексту
  - по центру над текстом
  - по центру під текстом
- анімація
- затримка анімації

### 5. Анімації для зображень

Для кожного зображення окремо можна вибрати:

- без анімації
- `Swing from top`
- `Swing from bottom`
- `Move left and right`
- `Blink`
- `Scale up`

### 6. Адаптивні значення для брейкпоінтів

Для таких параметрів підтримуються окремі значення для:

- `desktop`
- `tablet` — `max-width: 1200px`
- `mobile` — `max-width: 768px`

Підтримується для:

- `Text size`
- `Padding`
- `Margin`
- `Size` у зображень
- `Margin` у зображень

## Інтерфейс в адмінці

В адмінці реалізовано:

- окрему сторінку налаштувань
- підказки біля полів
- блок для керування зображеннями
- вибір зображень через стандартну медіабібліотеку WordPress
- візуальні іконки для полів responsive-налаштувань

## Як працює збереження даних

Плагін **не створює нових таблиць** у базі даних.

Усі налаштування зберігаються в стандартній таблиці WordPress:

- `wp_options`

Використовується одна опція:

- `wp_top_info_bar_settings`

Це означає:

- структура WordPress не змінюється
- додаткові таблиці не створюються
- плагін не втручається у схему бази даних

## Чи впливає плагін на стандартну роботу WordPress

Плагін не змінює стандартну поведінку WordPress на системному рівні.

Що він робить:

- додає один пункт меню в адмінці
- додає одну опцію в `wp_options`
- підключає свої CSS/JS-файли лише там, де це потрібно
- виводить інформаційний блок на фронтенді через WordPress-хуки

Що він **не робить**:

- не змінює ядро WordPress
- не створює нові таблиці
- не перезаписує шаблони теми
- не втручається у стандартні типи записів
- не змінює стандартні ролі або права доступу

## Технічна реалізація

Плагін побудований модульно:

- `wp-top-info-bar.php` — bootstrap-файл плагіна
- `includes/class-wp-top-info-bar.php` — ініціалізація
- `includes/class-wp-top-info-bar-settings.php` — дефолтні налаштування
- `includes/class-wp-top-info-bar-sanitizer.php` — санітизація даних
- `includes/class-wp-top-info-bar-admin.php` — адмінка
- `includes/class-wp-top-info-bar-frontend.php` — фронтенд-логіка
- `assets/css/admin.css` — стилі адмінки
- `assets/css/frontend.css` — стилі фронтенду
- `assets/js/admin.js` — логіка repeater-блоку і Media Library

## Підтримка теми

Плагін виводить блок через хук `wp_body_open`.

Це означає:

- у більшості сучасних тем блок буде працювати коректно
- якщо тема не підтримує `wp_body_open`, може знадобитися додатковий fallback

## Скріншоти

У папці `screens/` знаходяться приклади:

- адмінки плагіна
- вигляду блоку на сайті

## Підсумок

`WP Top Info Bar` — це плагін для керованого верхнього інформаційного блоку з текстом, зображеннями, анімаціями та адаптивними параметрами.

Він не змінює стандартну архітектуру WordPress, не створює нових таблиць і зберігає свої налаштування через стандартний механізм `wp_options`.
